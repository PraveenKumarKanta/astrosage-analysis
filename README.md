The Project contains call center data with 28k records and various analysis tasks.

The project is completely based on MS Excel and all tasks are completed using EXCEL, although certain tasks are accomplished using SQL for verifying KPI values.

The project contains following files:
  1. raw_data.xlsx
  2. cleaned_data.xlsx
  3. Complete_analysis_dashboard.xlsx (Contains all KPI extraction tasks)
  4. Presentation (in PPTX format)
  5. Presentation (in PDF format)
  6. final_dashboard.png (Screenshot of the active dashboard)
